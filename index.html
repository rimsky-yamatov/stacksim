Stack Machine Simulator

命令を1行ずつ実行するスタックマシン。値を積むときは push を明示します。

プログラム
1行につき1命令 / # 以降はコメント PC: -
準備完了。

read は入力待ちになります。値をセットしてから実行してください。

スタック
上端は青色で表示 0 items
スタックは空です
出力
命令一覧
push 値 値を積む
pop 取り除く
dup 複製
swap 上2つ交換
over 2番目を複製
rot 上3つを回転
add/sub/mul 算術
div/mod 除算・剰余
neg/abs 符号・絶対値
inc/dec ±1
eq/ne 等値・不等値
gt/lt/ge/le 比較
and/or/not 論理演算
clear 全消去
print 出力
read 入力
label: ラベル定義
goto label 無条件ジャンプ
goto label when gt 条件ジャンプ
halt 停止

算術・比較では、下側の値を左辺、先頭の値を右辺として扱います。
例: push 8 → push 3 → sub は 8 − 3。
比較命令は結果を積みますが、条件ジャンプの比較は値を消費しません。
値は数値、true、false、または二重引用符付き文字列です。
